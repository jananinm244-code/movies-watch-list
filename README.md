# 🎬 WatchList

A Netflix-inspired personal movie tracking web application that helps users
organize, search, and manage their favorite movies in one place.

## 📌 About the Project

WatchList is a simple and interactive movie management application designed
with a Netflix-inspired dark interface.

Users can browse movies, search for titles, filter movies based on their
watching status, add ratings and notes, and add their own movies to the
collection.

The application uses browser Local Storage to save movie data, so the
watchlist remains available even after refreshing the page.

---

## ✨ Features

- 🎬 Netflix-inspired dark theme
- 🔎 Search movies by title or genre
- 📌 Filter movies by watch status
- ⭐ Add movie ratings
- 📝 Add personal notes and reviews
- ➕ Add new movies
- 🗑️ Delete movies
- 🔄 Change movie status
- 📊 Watchlist statistics
- 💾 Local Storage for data persistence
- 📱 Responsive design for different screen sizes
